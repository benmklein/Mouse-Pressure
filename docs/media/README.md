# Release media

Keep optimized public README media here. Each demonstration has a compact GIF
for inline playback and a full-resolution H.264 MP4 linked from that preview:

- `pressure-writing.*` — pressure-sensitive writing in Krita;
- `pressure-coloring.*` — analog X-tilt moving a Krita brush through a color
  gradient; and
- `pressure-game.*` — analog control in the included physics sandbox.

Do not commit raw screen recordings. Crop away unrelated windows and personal
information, remove all audio streams and metadata, and keep GIFs short enough
to load comfortably on the GitHub repository page.
