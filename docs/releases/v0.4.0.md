# Mouse Pressure 0.4.0 Beta

Various fixes around multi monitor setups, logging improvements and additional QoL features.

## Changes

- Adds Toggle remap and Hold to deactivate modes.
- Accepts modifier and mouse-button combinations for remap, Start, and Stop
  shortcuts.
- Detects the mouse polling rate and adds a configurable rate while remapping. Stop restores the original rate.
- Handles multi-monitor setups more consistently.
- Keeps window title-bar interactions native and improves the first pressure
  stroke after a window is moved, resized, maximized, or restored.
- Adds an Open log folder action. Debug sessions create one compressed session
  file after Stop with logs, settings, monitor details, and stroke traces.
- Records monitor resolution, refresh rate, desktop position, and DPI scaling
  in diagnostic sessions.
- Improves fail-open cleanup and release synchronization when both analog
  buttons are used.
- Recovers cleanly when an existing install folder has lost its uninstall
  registration.
- Offers update/reinstall and uninstall choices when Setup finds an existing
  installation.

## Installation

Download `MousePressure-0.4.0-Setup.exe` and run it. The installer upgrades an
existing installation in place and keeps settings under `~/.mouse-pressure`.

The app is not Authenticode-signed, so Microsoft Defender SmartScreen may show
a warning. The installer does not install a kernel driver or require changes
to Secure Boot or driver-signature enforcement.

The installer SHA-256 is provided as a separate download.

## Tested compatibility

- Windows 10 x64 build 19045
- Compatible Logitech analog-button hardware over wired USB and Lightspeed
- Krita using **Windows 8+ Pointer Input**, Photoshop, and Microsoft Paint

## Known limitations

- Windows 11 is expected to work but has not been verified on physical Windows
  11 hardware.
- Polling rates above 1000 Hz are experimental and may cause jitter, especially
  at high display resolutions or non-default DPI scaling.
- The first stroke after pressing Start can occasionally register as a dot.
- Pen-property support varies between applications and brush presets.
- Anti-cheat compatibility is untested. Stop Mouse Pressure before launching
  an anti-cheat-protected game.

Use `Ctrl+F12` to Start and `Ctrl+Shift+F12` to Force Stop with default settings.
