# Mouse Pressure 0.3.0 Beta

This is the first beta release. It adds more ways to use analog button force
and makes ordinary desktop use less awkward while output is running.

## Changes

- Maps either analog button to tablet pressure, X-tilt, Y-tilt, rotation, or
  software mouse sensitivity.
- Adds configurable output ranges for tilt, rotation, and mouse sensitivity.
- Adds Always remap and Hold to remap modes. The hold shortcut defaults to
  Mouse 5 and can be changed.
- Adds configurable Start, Stop, and hold shortcuts.
- Reads, changes, and restores hardware actuation points with DPI and haptics.
  Mapping-on values initially match the detected mapping-off settings.
- Shows hardware actuation thresholds on the live mapping graph.
- Reworks the settings layout around a clear mouse-pressure-to-output flow.
- Hides logs and stroke analysis until Debug mode is enabled.
- Uses dark mode on first launch and remembers later theme changes.
- Recovers the first synthetic pen contact after a target window is maximized,
  restored, moved, or resized.
- Improves fail-open handling for suppressed buttons and hold-to-remap input.

## Installation

Download `MousePressure-0.3.0-Setup.exe` and run it. The installer upgrades an
existing installation in place and keeps settings under `~/.mouse-pressure`.

The app is not Authenticode-signed, so Microsoft Defender SmartScreen may show
a warning. The installer does not install a kernel driver or require changes
to Secure Boot or driver-signature enforcement.

The installer SHA-256 is provided as a separate download.

## Tested compatibility

- Windows 10 x64 build 19045
- Compatible Logitech analog-button hardware over wired USB and Lightspeed
- Krita using **Windows 8+ Pointer Input**, Photoshop, and Microsoft Paint

## Known limitations

- Windows 11 is expected to work but has not been verified on physical Windows
  11 hardware.
- The first stroke after pressing Start can occasionally register as a dot.
- Pen-property support varies between applications and brush presets.
- Anti-cheat compatibility is untested. Stop Mouse Pressure before launching
  an anti-cheat-protected game.

Use `Ctrl+F12` to Start and `Ctrl+Shift+F12` to Force Stop.
