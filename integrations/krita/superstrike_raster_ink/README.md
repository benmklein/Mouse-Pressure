# Superstrike Raster Ink Tool

This is a native Krita tool prototype with three explicit rendering modes:

1. **Native brush** (default) forwards Krita's original position, pressure,
   tilt, timestamps, and other tablet data unchanged. The active Krita preset
   owns size, opacity, texture, spacing, blending, and every sensor curve.
2. **Native brush + Ink Assist** keeps that same preset behavior while applying
   mild causal streamlining to X/Y and a small pressure low-pass before the
   preset's own pressure curve. Both filters strengthen gradually below 100%
   canvas zoom to reduce magnified screen-coordinate and sensor noise. It never
   replaces the stroke after release.
3. **Experimental Perfect Ink** retains the earlier filled-outline renderer.
   It cancels the native preview after release and commits a solid
   foreground-color outline generated by a native adaptation of Perfect
   Freehand. This mode deliberately cannot reproduce arbitrary Krita presets.

Separating these modes prevents a brief pause or release from unexpectedly
rerendering a normal brush stroke. Perfect Ink remains useful for clean solid
inking, while the two native modes preserve the selected brush exactly.

## Build and installation

Stage 2 has been compiled against the exact source commit used by Krita 5.3.3,
`858d352e52e68831693067763b9cdaf8bb9a05ce`, with Krita's supported Qt 5.15.7
and LLVM-MinGW toolchain. The standard Windows installer is a runtime rather
than a C++ SDK, so the reusable build environment lives under `E:\kd`.

Rebuild and install without administrator access:

```powershell
.\scripts\rebuild_krita_raster_ink.ps1
.\scripts\install_krita_raster_ink.ps1
```

The compiled DLL is copied to `dist/krita/5.3.3`. Installation uses
`%LOCALAPPDATA%\SuperstrikeKritaPlugins` and sets the per-user
`KRITA_PLUGIN_PATH`. A junction keeps all of Krita's built-in native plugins in
the same search tree. Restart Krita after installing.

To remove the per-user installation:

```powershell
.\scripts\install_krita_raster_ink.ps1 -Uninstall
```

## Defaults

- Rendering mode: Native brush
- Ink Assist path smoothing: 0.20
- Ink Assist pressure smoothing: 0.25
- Perfect Ink final smoothing: 0.00
- Perfect Ink final passes: 0
- Perfect Ink adaptive endpoint tails: enabled
- Perfect Ink maximum detected tail: 72 screen px
- Perfect Ink streamline: 0.50
- Perfect Ink outline smoothing: 0.50
- Perfect Ink pressure response: 1.00

The smoothing and pressure-correction reference implementation is
`src/superstrike_pressure/ink/raster_ink.py`; its tests let us tune behavior
against captured strokes before paying the cost of another Krita build.

Experimental Perfect Ink intentionally uses a solid foreground-color fill. It
uses Krita's current brush diameter as its maximum width, but it does not carry
over brush texture, opacity masks, or paint-engine effects. See
`THIRD_PARTY_NOTICES.md` for Perfect Freehand attribution and license terms.
